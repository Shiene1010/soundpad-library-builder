운영자 데모

요청 검토, 표현 제작, 배포 관리는 별도 운영자 흐름에서 진행합니다.

운영자 작업 순서
  1. 사용자 요청을 검토합니다.
  2. Gemini 초안을 바탕으로 chunk, tone, ccq를 완성합니다.
  3. 검증을 통과한 표현을 라이브러리에 추가합니다.
  4. GitHub `libraries/`와 manifest를 배포합니다.
